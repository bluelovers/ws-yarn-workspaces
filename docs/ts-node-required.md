# 需要使用 ts-node 的檔案清單

## 概述

本文件記錄了哪些 `.ts` 檔案無法使用 `tsx` 執行，必須改用 `ts-node`。

## 紀錄格式

當發現某個檔案無法使用 tsx 執行時，請在下方依以下格式新增紀錄：

```markdown
| 檔案路徑 | 失敗原因 | 發現日期 |
|----------|----------|----------|
| path/to/file.ts | 錯誤描述 | YYYY-MM-DD |
```
