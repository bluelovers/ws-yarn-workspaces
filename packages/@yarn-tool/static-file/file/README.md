## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add <%= name %>

# 使用 yarn-tool / Using yarn-tool
yarn-tool add <%= name %>
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add <%= name %>

# 使用 pnpm / Using pnpm
pnpm add <%= name %>

# 使用 npm / Using npm
npm install <%= name %>
```
