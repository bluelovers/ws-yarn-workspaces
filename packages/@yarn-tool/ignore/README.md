# README.md

    

## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add @yarn-tool/ignore

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @yarn-tool/ignore
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @yarn-tool/ignore

# 使用 pnpm / Using pnpm
pnpm add @yarn-tool/ignore

# 使用 npm / Using npm
npm install @yarn-tool/ignore
```
