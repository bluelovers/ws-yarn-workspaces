# @yarn-tool/yarnlock-banner

偵測並拆分 `yarn.lock` 開頭的自動產生橫幅（Banner）註解區塊，支援 Yarn v1 與 Berry（v2/v3）。

yarn.lock 檔案最前面一定會有一段 `#` 開頭的宣告文字（v1 是 `# THIS IS AN AUTOGENERATED FILE...`，Berry 則是 `# This file is generated by running "yarn install"...`）。本套件把這段橫幅與真正的鎖定檔內容切開，方便在改寫、比對或合併 lockfile 時單獨處理橫幅。

## Features

- 自動收集檔案開頭的註解列（`#` 開頭）與空列，直到遇到第一行非註解內容為止
- 回傳的 `banner` 與 `content` 皆以 `LF` 換行，不受來源檔案是 `CRLF` 或 `LF` 影響
- 無橫幅時 `banner` 為空字串，`content` 則完整保留原始內容，不會誤刪資料
- 提供 `EnumYarnLockBanner` 列舉（Enum），可取得 v1 / Berry 的標準橫幅文字
- 僅依賴 [`crlf-normalize`](https://www.npmjs.com/package/crlf-normalize)，無其他相依

## Installation

```bash
yarn add @yarn-tool/yarnlock-banner
yarn-tool add @yarn-tool/yarnlock-banner
yt add @yarn-tool/yarnlock-banner
```

## Usage

### 拆出橫幅與內容

```ts
import { existsYarnLockBanner } from '@yarn-tool/yarnlock-banner'
import { readFileSync } from 'fs'

const { banner, content } = existsYarnLockBanner(readFileSync('yarn.lock'))

console.log(banner)  // '# THIS IS AN AUTOGENERATED FILE...'
console.log(content) // 從第一個非註解列開始的 lockfile 內容
```

### 預設匯入

```ts
import existsYarnLockBanner from '@yarn-tool/yarnlock-banner'

const result = existsYarnLockBanner(rawText)
```

### 取得標準橫幅文字

```ts
import { EnumYarnLockBanner } from '@yarn-tool/yarnlock-banner'

// const enum，編譯期即被替換為字面值
EnumYarnLockBanner.v1 // '# THIS IS AN AUTOGENERATED FILE. DO NOT EDIT THIS FILE DIRECTLY.\n# yarn lockfile v1'
```

## API Documentation

### `existsYarnLockBanner(yarnlock_old): { banner: string, content: string }`

萬用入口函式（Default Export）。以 `R_CRLF` 切割輸入後，逐列掃描直到第一個「非空列且不以 `#` 開頭」的列為止，據此分成兩部分。

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `banner` | `string` | 橫幅文字，已正規化為 `LF` 並去除頭尾空行；非空時結尾會補上 `\n\n` |
| `content` | `string` | 橫幅之後的 lockfile 內容，以 `LF` 重新串接 |

**參數**

| 名稱 | 型別 | 說明 |
| --- | --- | --- |
| `yarnlock_old` | `Buffer \| string` | lockfile 原始內容 |

> 橫幅結尾刻意補 `\n\n`：重新組合 `banner + content` 時會自然產生一個空列，與 yarn 原生輸出格式一致。

### `EnumYarnLockBanner`

橫幅文字的列舉（編譯期常數列舉 `const enum`）：

| 成員 | 值 |
| --- | --- |
| `v1` | `# THIS IS AN AUTOGENERATED FILE. DO NOT EDIT THIS FILE DIRECTLY.\n# yarn lockfile v1` |
| `v2` | `# This file is generated by running "yarn install" inside your project.\n# Manual changes might be lost - proceed with caution!` |

Berry 的 v2 與 v3 使用同一段橫幅文字，來源見 [yarnpkg/berry 的 Project.ts](https://github.com/yarnpkg/berry/blob/4a097fa80c0fc42e3d5eb51c597bf7304e981111/packages/yarnpkg-core/sources/Project.ts#L1739)。

## Configuration

本套件無需任何設定檔或環境變數。

換行（Newline）處理固定為：切割時相容 `CRLF` / `LF`（`R_CRLF`），輸出一律為 `LF`，由 `crlf-normalize` 提供。

若需要進一步操作 lockfile，可搭配同系列套件：

- [`@yarn-tool/yarnlock-stringify`](../yarnlock-stringify/README.md) — 把解析後的物件還原成 lockfile 文字
- [`@yarn-tool/detect-yarnlock-version`](../detect-yarnlock-version/README.md) — 偵測 lockfile 版本
